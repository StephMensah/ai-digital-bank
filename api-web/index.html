Decisioned, not just routed

Every instruction is scored before the money moves. Clear payments go straight through, risky ones open a case and hold the funds, and if the model is unreachable the rules take over so nothing stalls.

Rails that reach everyone

MTN MoMo for wallets, GhIPSS GIP for interbank credit transfers with name enquiry before the send, Paystack for cards. One API, one reference, one reconciliation.

The core stays the truth

Settlement writes double-entry ledger lines, then queues the posting to Mambu. Anything that drifts shows up in the control tower rather than in a customer's balance.
